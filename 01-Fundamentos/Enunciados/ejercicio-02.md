# Ejercicio 02 — Registro de temperaturas

Crea un programa que registre varias mediciones de temperatura y muestre un resumen al finalizar.

El usuario debe introducir primero cuántas mediciones quiere realizar.

Después, el programa debe pedir cada temperatura una a una.

Al finalizar, debe mostrar:

* Temperatura media.
* Temperatura máxima.
* Temperatura mínima.
* Número total de mediciones.

## Restricciones

* Usa un bucle `for`.
* Usa `range()`.
* No uses listas.
* No uses funciones.
* No uses librerías.
* No es necesario validar entradas incorrectas.
* Usa `if` cuando sea necesario.

## Ejemplo de salida por consola

```text
Número de mediciones: 4

Temperatura 1: 21.5
Temperatura 2: 23.0
Temperatura 3: 19.8
Temperatura 4: 22.7

Temperatura media: 21.75 °C
Temperatura máxima: 23.00 °C
Temperatura mínima: 19.80 °C
Número de mediciones: 4
```
