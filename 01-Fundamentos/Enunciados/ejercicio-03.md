# Ejercicio 03 — Análisis de números

Crea un programa que analice una serie de números introducidos por el usuario.

El usuario debe indicar primero cuántos números quiere introducir.

Después, el programa debe pedir cada número uno a uno.

Al finalizar, debe mostrar:

* Suma total.
* Media.
* Número mayor.
* Número menor.
* Cantidad de números positivos.
* Cantidad de números negativos.
* Cantidad de ceros.

## Restricciones

* Usa un bucle `for`.
* Usa `range()`.
* No uses listas.
* No uses funciones.
* No uses librerías.
* No es necesario validar entradas incorrectas.
* Usa acumuladores y contadores cuando sea necesario.

## Ejemplo de salida por consola

```text
Número de valores: 5

Valor 1: 4
Valor 2: -2
Valor 3: 0
Valor 4: 7
Valor 5: -1

Suma total: 8.00
Media: 1.60
Mayor: 7.00
Menor: -2.00
Positivos: 2
Negativos: 2
Ceros: 1
```
