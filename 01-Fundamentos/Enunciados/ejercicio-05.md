# Ejercicio 05 — Adivinar una contraseña

Crea un programa que pida al usuario una contraseña hasta que introduzca la correcta.

La contraseña correcta será:

```text
python123
```

Mientras la contraseña sea incorrecta, el programa debe seguir solicitándola.

Cuando el usuario introduzca la contraseña correcta, debe mostrar un mensaje de acceso concedido y terminar.

Además, debe contar cuántos intentos ha necesitado el usuario.

## Restricciones

* Usa un bucle `while`.
* No uses `for`.
* No uses listas.
* No uses funciones.
* No uses librerías.
* No es necesario limitar el número de intentos.

## Ejemplo de salida por consola

```text
Introduce la contraseña: hola
Contraseña incorrecta.

Introduce la contraseña: python
Contraseña incorrecta.

Introduce la contraseña: python123
Acceso concedido.
Número de intentos: 3
```
