# Ejercicio 06 — Cuenta regresiva

Crea un programa que pida al usuario un número entero positivo y muestre una cuenta regresiva hasta llegar a `0`.

El programa debe mostrar cada valor en una línea distinta.

Al finalizar, debe mostrar:

```text
Fin
```

## Restricciones

* Usa un bucle `while`.
* No uses `for`.
* No uses listas.
* No uses funciones.
* No uses librerías.
* No es necesario validar entradas incorrectas.

## Ejemplo de salida por consola

```text
Introduce un número: 5

5
4
3
2
1
0
Fin
```
