# Ejercicio 09 — Lista de temperaturas

Crea un programa que permita introducir varias temperaturas y almacenarlas en una lista.

El usuario debe indicar primero cuántas temperaturas quiere introducir.

Después, el programa debe pedir cada temperatura y guardarla.

Al finalizar, debe mostrar:

* La lista completa de temperaturas.
* Cada temperatura en una línea distinta.
* El número total de temperaturas almacenadas.

## Restricciones

* Usa una lista.
* Usa un bucle `for`.
* Usa `range()`.
* Añade los valores a la lista uno a uno.
* No uses funciones propias.
* No uses librerías.

## Ejemplo de salida por consola

```text
Número de temperaturas: 4
Temperatura 1: 21.5
Temperatura 2: 18.2
Temperatura 3: 23.0
Temperatura 4: 19.7

Temperaturas: [21.5, 18.2, 23.0, 19.7]

Temperatura: 21.5 °C
Temperatura: 18.2 °C
Temperatura: 23.0 °C
Temperatura: 19.7 °C

Número de temperaturas: 4
```
