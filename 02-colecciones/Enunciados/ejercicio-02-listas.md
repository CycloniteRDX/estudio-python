# Ejercicio 02 — Análisis de una lista de números

Crea un programa que permita introducir varios números y almacenarlos en una lista.

El usuario debe indicar primero cuántos números quiere introducir.

Después, el programa debe pedir cada número y guardarlo en la lista.

Al finalizar, debe mostrar:

* La lista completa.
* El número mayor.
* El número menor.
* La suma de todos los números.
* La media.
* Cuántos números son positivos.
* Cuántos números son negativos.
* Cuántos ceros hay.

## Restricciones

* Usa una lista.
* Usa `for`.
* Añade los valores con `.append()`.
* Recorre la lista después de haber introducido todos los valores.
* No uses funciones propias.
* No uses librerías.
* No uses `max()`, `min()` ni `sum()` todavía.
* No es necesario validar entradas incorrectas.

## Ejemplo de salida por consola

```text
Número de valores: 5
Valor 1: 4
Valor 2: -2
Valor 3: 0
Valor 4: 7
Valor 5: -1

Lista: [4, -2, 0, 7, -1]
Mayor: 7
Menor: -2
Suma: 8
Media: 1.60
Positivos: 2
Negativos: 2
Ceros: 1
```
