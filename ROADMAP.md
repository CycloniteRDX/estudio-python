# Roadmap de Python

## 1. Fundamentos

* Variables y tipos básicos
* Operadores
* Entrada y salida por consola
* Conversión de tipos
* Condicionales
* Bucles `for` y `while`
* `range()`
* Funciones básicas

## 2. Colecciones

* Listas
* Tuplas
* Diccionarios
* Conjuntos
* Recorrido de colecciones
* Búsqueda y modificación de datos
* Comprensiones básicas

## 3. Funciones

* Parámetros y argumentos
* `return`
* Ámbito de variables
* Valores por defecto
* Argumentos por nombre
* Separación del programa en funciones

## 4. Cadenas de texto

* Indexado y slicing
* Métodos principales
* Formateo con f-strings
* Procesamiento básico de texto

## 5. Archivos y errores

* Lectura de archivos

## 6. Módulos

* `import`
* Crear módulos propios
* Organización en varios archivos
* Librería estándar
* Instalación de paquetes con `pip`

## 7. Programación orientada a objetos

* Clases y objetos
* Atributos
* Métodos
* `__init__`
* Atributos de instancia y de clase
* Encapsulación básica
* `@staticmethod`
* `@classmethod`

## 8. Herencia y polimorfismo

* Herencia
* `super()`
* Sobrescritura de métodos
* Polimorfismo
* Composición frente a herencia

## 9. Python intermedio

* Desempaquetado
* `*args` y `**kwargs`
* Iteradores
* Generadores
* Funciones lambda
* `map()`, `filter()` y alternativas más legibles
* Type hints básicos

## 10. Estructura de programas

* Separar lógica y entrada/salida
* Organización por módulos
* Uso de `main()`
* `if __name__ == "__main__"`
* Manejo de configuración
* Diseño de programas pequeños

## 11. Datos

* CSV
* JSON
* SQLite
* Consultas SQL básicas desde Python
* Conversión entre objetos y datos almacenados

## 12. Interfaces gráficas

* Fundamentos de Qt
* Widgets
* Señales y slots
* Qt Designer
* Separación entre interfaz y lógica

## 13. Python aplicado a informática industrial

* Comunicación con dispositivos
* Puertos serie
* Adquisición de datos
* OPC UA
* Bases de datos
* Interfaces SCADA sencillas
* Registro y visualización de datos

## Objetivo

Ser capaz de diseñar y escribir programas pequeños y medianos en Python, entender código ajeno y utilizar Python como herramienta para automatización e informática industrial.
